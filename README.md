# Desenvolvimento Web





Este repositório reúne os exercícios e desafios desenvolvidos durante as aulas do curso Técnico em Desenvolvimento de Sistemas no SENAI, com foco nas linguagens HTML e CSS.



O objetivo deste repositório é registrar e demonstrar a evolução no aprendizado de desenvolvimento web, aplicando conceitos de estruturação semântica, estilização de páginas, e design responsivo.



🛠️ Tecnologias Utilizadas



- HTML


- CSS


- JavaScript


- NodeJS


- Bootstrap







🎯 Objetivos do Repositório



Praticar os conceitos fundamentais de HTML e CSS



Desenvolver páginas web estáticas e bem estruturadas



Explorar propriedades de layout, cores, tipografia e responsividade



Consolidar o aprendizado em desenvolvimento front-end básico







📂 Conteúdo



Exercícios de marcação e estrutura HTML



Atividades de estilização com CSS



Desafios de layout e posicionamento de elementos



Páginas responsivas para diferentes dispositivos
